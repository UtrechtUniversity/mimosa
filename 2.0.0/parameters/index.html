    Parameter reference

    Configurable parameters

    time

    start

    Year in which the model starts

    • Type: int

    • Default: 2025

    • Min: 1900

    • Max: 2100

    Example usage: 

    params = load_params()
params["time"]["start"] = 2025
model = MIMOSA(params)
    end

    Last year of the model run

    • Type: int

    • Default: 2150

    • Min: 1901

    • Max: 2300

    Example usage: 

    params = load_params()
params["time"]["end"] = 2150
model = MIMOSA(params)
    dt

    Initial timestep length in years

    • Type: float

    • Default: 5

    • Min: 0.5

    • Max: 20

    Example usage: 

    params = load_params()
params["time"]["dt"] = 5
model = MIMOSA(params)
    periods

    Optional timestep changes, mapping each change year to the timestep length in years used after that year

    • Type: dict

    • Default: {2050: 10}

    Example usage: 

    params = load_params()
params["time"]["periods"] = {2050: 10}
model = MIMOSA(params)
    SSP

    SSP, used for population, baseline GDP and baseline emissions

    • Type: enum

    • Default: SSP2

    • Allowed values:

      • SSP1
      • SSP2
      • SSP3
      • SSP4
      • SSP5

    Example usage: 

    params = load_params()
params["SSP"] = "SSP2"
model = MIMOSA(params)

    LBD_rate

    Learning by doing rate: reduction in marginal mitigation costs for doubling cumulative mitigation capacity. Empirical studies show values between 0.65 (high learning) and 0.95 (low learning)

    • Type: float

    • Default: 0.82

    • Min: 0.1

    • Max: 1

    Example usage: 

    params = load_params()
params["economics"]["MAC"]["LBD_rate"] = 0.82
model = MIMOSA(params)
    LBD_scaling

    Scaling factor for learning by doing to transform the units of cumulative mitigation in relative terms (compared to baseline emissions in t=0). Only used for calibration, and should not be used to change the amount of LBD (for this, use economics > MAC > LBD_rate)

    • Type: quantity

    • Default: 40 GtCO2

    • Unit: emissions_unit

    Example usage: 

    params = load_params()
params["economics"]["MAC"]["LBD_scaling"] = "40 GtCO2"
model = MIMOSA(params)
    LOT_rate

    Learning rate of exogenous learning (learning over time). By default, there is no exogenous learning assumed, as all the technological learning happens endogenously (learning by doing).

    • Type: float

params["economics"]["MAC"]["LOT_rate"] = 0

    economics > damages > accreu
    adaptation

    Enable sector-specific adaptation with "sectoral", disable it with "noadaptation", or use "combined" labour productivity and riverine flooding adaptation for diagnostics and model comparisons.

    • Type: enum

    • Default: noadaptation

    • Allowed values:

      • sectoral
      • combined
      • noadaptation

    Example usage: 

    params = load_params()
params["economics"]["damages"]["accreu"]["adaptation"] = "noadaptation"
model = MIMOSA(params)
    cba_strategy

    How solve() coordinates mitigation and adaptation in an ACCREU cost-benefit analysis. The sequential strategy first optimises mitigation without adaptation and then calculates analytical optimal adaptation for that pathway. The joint strategy uses the ordinary one-model solve path, with adaptation either chosen by the solver or determined analytically.

    • Type: enum

    • Default: mitigation_then_adaptation

    • Allowed values:

      • mitigation_then_adaptation
      • joint

    Example usage: 

    params = load_params()
params["economics"]["damages"]["accreu"]["cba_strategy"] = "mitigation_then_adaptation"
model = MIMOSA(params)
    adaptation_determination

    How ACCREU adaptation expenditure is determined. With solver_control it is a free optimisation or simulation control. With analytical_optimum it is calculated from the analytical optimal-adaptation equation.

    • Type: enum

    • Default: analytical_optimum

    • Allowed values:

      • solver_control
      • analytical_optimum

    Example usage: 

    params = load_params()
params["economics"]["damages"]["accreu"]["adaptation_determination"] = "analytical_optimum"
model = MIMOSA(params)
    adaptation_calibration

    Calibration of the sectoral ACCREU adaptation curves. "accreu" uses the original source-model coefficients. The three "literature" options use realised-effectiveness caps and cost multipliers calibrated to the low, central, and high ends of literature benefit-cost ranges at a 5% discount rate. They apply to both separate and combined adaptation.

    • Type: enum

    • Default: accreu

    • Allowed values:

      • accreu
      • literature_low
      • literature
      • literature_high

    Example usage: 

    params = load_params()
params["economics"]["damages"]["accreu"]["adaptation_calibration"] = "accreu"
model = MIMOSA(params)
