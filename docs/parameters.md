## Time- and region-dependent parameters

The plots show initialised SSP2 values for all 26 IMAGE regions, from 2025 to 2100,
using the indicated model configuration. Parameters whose values are all zero or
uninitialised are omitted.
Values use the model's default time grid: five-year steps through 2050, then ten-year steps.
Each line represents one region. Hover to inspect values,
click a legend entry to hide a region, or double-click it to isolate that region.
